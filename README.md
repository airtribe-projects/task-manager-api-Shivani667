# Task Manager API

A simple task management REST API built with **Express.js**.  
It supports creating, reading, updating, and deleting tasks, with fields for `title`, `description`, and `completed`.

## Features
- Create a new task with `title`, `description`, and optional `completed` status
- Retrieve all tasks or filter by completion status
- Get a single task by ID
- Update a task’s title, description, or completion status
- Delete a task by ID

## Requirements
- Node.js (>= 14)
- npm or yarn
